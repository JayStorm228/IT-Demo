# 04 — Информационные системы

## Темы-кандидаты
- Понятие информационной системы.
- Пользовательские требования и техническое задание.
- Реляционная модель данных, таблицы, ключи и связи.
- Нормализация и целостность данных.
- SQL: выборка, фильтрация, соединения, группировка и изменение данных.
- Диаграммы сущность–связь и другие модели.
- Архитектура приложения и разделение ответственности.
- Безопасность, проверка входных данных и резервное копирование.
- Техническая документация.

Состав тем будет скорректирован под образовательную программу и актуальный КОД.
