# 02 — Основы с нуля

Вводный курс для тех, кто начинает программировать с нуля. Каждая тема должна включать простое объяснение, небольшой пример и самостоятельное упражнение.

## Предлагаемый порядок
1. Как устроена программа и как запускать код.
2. Переменные, значения и типы данных.
3. Выражения и логические операции.
4. Условия и ветвления.
5. Циклы.
6. Функции и разбиение задачи на части.
7. Коллекции и строки.
8. Алгоритмы, поиск ошибок и отладка.
9. Основы объектно-ориентированного программирования.
10. Чтение документации и незнакомого кода.

Основной язык выбирается после сверки с образовательной программой и требованиями экзамена. Не нужно изучать несколько языков одновременно на старте.
