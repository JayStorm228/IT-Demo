# Настройка Obsidian

## Рекомендуемые настройки

- **Файлы и ссылки → Расположение вложений:** папка «Вложения».
- **Файлы и ссылки → Расположение новых заметок:** текущая папка.
- **Файлы и ссылки → Обновлять внутренние ссылки:** включено.
- **Основные плагины → Шаблоны → Папка шаблонов:** «Шаблоны».
- **Основные плагины → Ежедневные заметки → Папка:** «01 — План подготовки/Ежедневные заметки».
- **Формат ежедневной заметки:** YYYY-MM-DD.
- **Удаление файлов:** локальная корзина Obsidian.

## Встроенные плагины

Для старта достаточно включить Файловый менеджер, Поиск, Быстрый переход, Обратные ссылки, Исходящие ссылки, Свойства, Структура документа, Предварительный просмотр страницы, Шаблоны, Ежедневные заметки, Палитру команд, Закладки, Количество слов и Восстановление файлов. Граф можно включить по желанию.

## Сторонние плагины

Сторонние плагины по умолчанию отключены: так хранилище проще открыть на чистой установке и проще объяснять новичкам. В репозитории могут оставаться файлы плагинов, скопированные из прежней конфигурации; не включай их автоматически.

Если решишь настроить автоматическую синхронизацию через Git, сначала проверь, какие файлы будут отправляться в публичный репозиторий. Локальная раскладка вкладок Obsidian не должна попадать в общий репозиторий.

## Где лежат технические настройки

Файлы конфигурации находятся в скрытой папке .obsidian. Краткая техническая заметка для GitHub хранится в [README настроек](.obsidian/README.md).
