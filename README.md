# IT-Demo — подготовка к демонстрационному экзамену с нуля

Открытая учебная база для подготовки к демонстрационному экзамену по специальности **09.02.07 «Информационные системы и программирование»**, квалификация **«Специалист по информационным системам»**. Целевой год — **2028**.

Цели: подготовиться по официальным материалам, понять темы с нуля и создать полезный курс для других начинающих.

> **Важно:** комплект оценочной документации (КОД) и критерии для экзамена 2028 года необходимо сверить с официальными публикациями и материалами образовательной организации. Прошлые варианты не гарантируют формат экзамена 2028 года.

## Принципы
- Сначала простое объяснение, затем пример и самостоятельная практика.
- Разделять официальные требования, учебную основу и дополнительные темы.
- Указывать источник и дату проверки важных материалов.
- Не публиковать персональные данные, пароли, ключи доступа и приватные материалы колледжа.
