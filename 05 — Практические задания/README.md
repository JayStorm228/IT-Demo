# 05 — Практические задания

## Уровни сложности
1. **Повторение:** упражнение на один навык.
2. **Применение:** задача из нескольких шагов.
3. **Интеграция:** небольшая законченная задача по нескольким темам.
4. **Экзаменационная тренировка:** комплексная задача по подтверждённым критериям.

## Стандарт каждой задачи
- Условие и исходные данные.
- Ожидаемый результат.
- Критерии проверки.
- Ограничения и тестовые случаи.
- Подсказка отдельно от условия.
- Разбор решения отдельно от подсказки.
- Типичные ошибки.
- Связанные темы и источник.

Используй [[Шаблоны/Практическое задание|шаблон практического задания]]. Не публикуй закрытые оценочные материалы, если их распространение не разрешено.
